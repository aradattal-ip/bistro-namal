# ביסטרו נמל — אתר דמו להדגמת ווקלי

אתר של מסעדה **בדיונית**, שמשמש להדגמת הקמת לקוח בווקלי על ידי שאיבת נתונים מהאתר (גילוי אוטומטי).

- כתובת: https://aradattal-ip.github.io/bistro-namal/
- 5 עמודים סטטיים: בית, תפריט, סניפים, שאלות נפוצות, צור קשר ומשלוחים.
- כל הטלפונים, הכתובות והמייל בדיוניים. האתר מסומן `noindex`.
- התמונות הן תמונות חינמיות מ-Unsplash, ונטענות ישירות מהשרתים של Unsplash. המזהים שלהן מרוכזים ב-`PHOTOS` שב-`tools/build_site.py`.

## מה הסורק שולף מהאתר
שם העסק ותיאור, 3 סניפים (כתובת, עיר, טלפון, כשרות, שעות), 36 מנות עם מחירים, 14 שאלות ותשובות ו־7 שדות מותאמים (מדף הבית).

## עריכה
את ה-HTML לא עורכים ידנית. משנים את הנתונים ב-`tools/build_site.py` ומריצים:

```bash
python3 tools/build_site.py
```

### כללים, כדי שהסורק ימשיך לקרוא נכון
- הסורק לא מריץ JavaScript, ולכן כל התוכן חייב להיות ב-HTML.
- הסורק קורא את דף הבית ועוד 4 קישורים מהניווט.
- הסימן ₪ מופיע רק במחירי מנות. בכל מקום אחר כותבים "שקלים".
- המילה "סניף" (ביחיד) מופיעה רק בשורת הסניף עצמה.
- נקודתיים מופיעים רק בשורות של עובדות מהסוג "תווית: ערך".
- סימן שאלה מופיע רק בשורות "שאלה:".
- שורת הפרטים של כל סניף כתובה בשורת מקור אחת.
